# The Awards Watch

Static public Oscars and Emmys watchlist with personal reactions and subscribable Canadian release calendar.

## Publish
In GitHub repository Settings → Pages → Deploy from a branch → main / (root) → Save. The URL will be https://idyllic-stroopwafel.github.io/awards-watch/.

## Calendar
The releases.ics file is intentionally empty until Canadian release dates are verified. Subscribe by URL in Google Calendar; Google determines refresh timing. Stable event UIDs and all-day DATE fields should be used for future updates.

## Privacy
Owner's viewing reactions are intentionally public. Visitor checklist selections stay in their browser via localStorage.

## Updating
Verify Canadian dates from primary distributors, cinemas, and streaming services. Update data.json and releases.ics together. The monthly ChatGPT report does not automatically publish commits. No Netlify credits, server, or paid API required.
